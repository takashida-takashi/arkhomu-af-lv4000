# はこホム AF Lv4000予測

はこホムのアーティファクトが、Lv4000でどのくらいの性能になりそうかをゲーム画面で見比べられるChrome・Edge用の拡張機能です。

- **AFの詳細**では、Lv4000未満のAFの現在値の下に予測値が出ます。「Lv4000予測をコピー」で予測結果をテキストにできます。Lv4000以上のAFでも、AF変換率とドロップ率の現在の合計を確認できます。スクリーンショットを撮るときなどは、詳細の上部右側にある「予測 ON / OFF」で拡張の表示だけを切り替えられます。設定は別のAFを開いたりページを再読み込みしたりしても引き継がれます。
- **予測で絞り込み**は、装備・強化・分解タブ、フリーマーケット、オークション、個人間取引のアーティファクトタブで使えます。パラメータと特性を検索するか、カテゴリを開いてチェックします。体力などのパラメータも選べ、各項目に下限・上限と、その項目自身の★を指定できます。20%以上なら下限に `20` と入力します。
- **複数条件**はAND（すべて一致）、OR（どれか1つ）、「指定数以上」でつなぎます。会心威力・会心率・会心耐性を追加して「指定数以上」の数を `2` にすると、3項目中2項目以上に一致したAFを表示できます。「＋ グループ」で入れ子にでき、内側のグループは外側の条件では1件として数えます。最低一致数もプリセットに保存できます。
- **プリセット**は、名前を入力して「保存」を押します。次回は一覧から名前を選び「読み込み」で、条件、予測値・判定できないAFの表示設定、拡張側の並び順を戻せます。同じ名前の「上書き保存」で更新できます。プリセットは同じChromeプロファイルの拡張機能内に保存されます。分解タブの「残す」チェックはプリセットに含まれません。
- **並び順**では、ゲームの並び順の先頭から「AF変換率＋ドロップ率合計」を選べます。横の「予測値順」にチェックすると、パワー・パラメータ・特性・合計の順番にLv4000予測値を使います。「予測で絞り込み」の並び順からも、比較する項目と高い順・低い順を選べます。ポップアップで項目を選んだときは、ポップアップ側の並び順を優先します。

## 拡張設定

画面右上のメニューで、ゲームの「設定」の隣にある「拡張設定」を開くと、機能を個別にオン／オフにできます。

- **AFガチャ・スーパーガチャ**では、公開されたAFのカードにパワー（PW）と、そのレベルでのAF変換率＋ドロップ率合計を表示します。
- **探索結果**の標準カードと前後ボタンで、「標準の件数」「全件表示」「優先度別ページ」を使えます。全AFレアリティ・通常アイテム・特殊アイテム・魂・卵などの表示順とページ割り当ては「拡張設定」で変更できます。条件に合ったAFは赤い枠と「✓」が付き、一致した項目名と値が最大2件出ます。「✓」のある欄を押すと、すべての一致条件を上下限・★と合わせて確認できます。並び順に使った項目と値は別の段に出ます。「→」はLv4000予測を示します。枠の色と、候補を先頭に寄せるか候補に絞るかは拡張設定で選べます。
- **AFドロップ合計**は、探索結果で獲得した全レア度のAFの個数を表示します。絞り込みやページ切り替えの前の合計が表示されます。
- **探索の獲得量**は、1ストックあたりのAF・経験値・ゴールドと、戦闘の勝率・勝敗数を今回、直近30日（日本時間）、累計で表示します。獲得量は各期間の合計をストック数の合計で割り、勝率は戦績を記録できた結果の合計勝数を合計戦闘数で割ります。通常探索の集計はブラウザ内に保存され、探索結果の「統計をリセット」や「拡張設定 → 探索結果」から次の探索分で集計し直せます。ギルダンは今回分を表示し、そのダンジョンの1ストックあたりの戦闘回数（取得できない場合は5戦）で換算します。ギルダンの試走や挑戦全体の報酬しか分からない結果、ボス戦、天昇の塔は通常探索の集計対象外です。
- **フリマの最安値の推移**は、通常アイテムや永久スキルを選び、「最安値を追跡」から登録します。通常アイテムはフリマの標準画面に読み込まれた最安値で更新し、永久スキルはスキル個別の価格が分かったときに更新します。追跡中のスキルは「価格を確認」から1件ずつ確認でき、出品が複数ページあるときは標準の「価格が安い順」で確認できます。100件まで、商品ごとに価格が変わった時点を最大90回このブラウザに保存します。
- 自分のプロフィールの **称号設定 → 隠し称号** に、未取得の称号が鍵付きで並びます。標準の検索や「獲得済みだけ」が使えます。鍵付きの称号も入手条件を確認でき、数値が不明な箇所は `N` で表示します。
- **AF強化の費用の目安**は、強化画面で対象を選び、必要素材の下にある「Lv4000までの強化費用の目安」を開くと見られます。期待値と約90%到達に必要な素材数、素材代、研究軽減込みの強化費用、合計が表示されます。フリマで素材を開いて読み込まれた売上平均を、同じブラウザで24時間使えます。単価は手入力でも変更できます。
- **スキルプリセット**は、ホムンクルスごとに使用中と控えの状態を保存します。プリセットを選ぶと変更箇所を表示するので、ゲームの控えボタンで切り替えてください。
- **ホームの拡張通知**は項目別にオン／オフにできます。NPCショップ・ギルドショップ・ギルドボスは、当日分の実績を確認するまで「未実行（未確認）」と表示します。画面で確認した状態をこのブラウザに保存し、日本時間の0時に日次分を更新します。NPCショップの陳列が先に更新される場合はその時刻、勲章交換は週の更新時刻が区切りです。
- **孵化**は完了時刻が最も早い1件を「最短の孵化予定」と表示します。終了間近のオークションは、ホームにあるゲーム標準の欄で確認できます。
- **スロット**は、「拡張設定」→「ホームの通知」で低・中・高・超高レートの通知を個別に切り替えられます。スロット画面で確認した今の部の残り回転数を表示します。部の切り替えは日本時間3:30と19:30です。超高レートは確認できる国営ホールで読み込みます。
- **ギルドボスの通知**は、標準画面の「本日の残り参加回数」を読み取ります。画面を開けば、別の端末で消化した分も反映されます。このブラウザで確認した当日の戦果でも更新し、残り0回で通知が消えます。模擬戦と返却された挑戦は回数に含めません。
- **その他の通知**では、採取地の満杯やコロシアムの未使用チケット数などを表示します。
- **チャット**では、引用を押すと表示中の返信元へ移動します。返信元が非表示の場合は、読み込み済みの元の本文か、返信に保存された引用をその場で1件だけ表示します。本体が引用欄も隠しているときは「非表示の返信元を見る」から開けます。
- **今日の増減**では、日本時間の0時で日付を切り替え、その日に最初に確認できた残高からゴールドとスタミナポーションの増減を表示します。

### 通常アイテムの所持数を表示する

1. ゲームの「持ち物」で「通常」タブを開きます。
2. アイテム倉庫でアイテムを選び、詳細欄の「ホーム通知に追加」を押します。複数登録できます。
3. 必要なら同じ欄に目標数を入れます。ホームの拡張通知に「黒曜石 84,000 / 100,000」のように表示され、到達すると「目標達成」が付きます。解除もアイテム詳細から行います。

ゲームが所持数を読み込むと表示も更新されます。再読み込み直後など、所持数を確認できない間は前回確認した個数と時刻を表示します。目標数と登録内容はアカウントごとにこのブラウザに保存されます。
ホームの素材通知を押すと、倉庫で該当アイテムの詳細を開きます。

## 入れ方

1. ZIPを展開します。
2. Chromeのアドレス欄で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` が入っている `arkhomu-af-lv4000` フォルダを選びます。
4. はこホムを再読み込みして、AF一覧の「並び替え・絞り込み」にある「予測で絞り込み」を開きます。

Edgeでは `edge://extensions` を開いて、同じようにフォルダを読み込みます。

## 分解するAFを選ぶ

1. 分解タブの「予測で絞り込み」で、残したいAFの条件を作ります。
2. 一致したAFを確認し、残したいカードの「残す」にチェックを付けます。「一覧の一致をすべて残す」でもまとめてチェックできます。
3. 条件外だけを見たい場合は「条件に一致しないAF」、一致していても残すチェックを付けなかったAFを含める場合は「残すチェックがないAF」に切り替えます。装備中・お気に入り・装備プリセット登録中のAFや、判定できないAFは分解候補から外れます。
4. ゲームの一括解体モードで表示されたカードを選択し、ゲーム側の確認画面で対象を確認します。残すチェックは拡張内の目印です。ゲーム側に前の選択が残っている場合は、いったん選択を終了してから選び直してください。

## フィルターの範囲

装備・強化・分解では、ゲームが読み込んだ一覧を先に絞り込むので、「全件」表示でも一致するAFが上から詰まります。フリマとオークションの絞り込みと予測値順は、いま開いているページが対象です。オークションでは「開催中の出品」にある「予測で絞り込み」から、条件と並び順を設定できます。ページを切り替えても条件は引き継がれます。標準の特性条件に下限を入れると現在値で先に除外されるので、予測値で比較したい下限は拡張の欄に入れてください。値を読み取れないAFがある場合は「判定できないAFも表示」で一覧に戻せます。

すでに前の版を入れている場合は、新しいファイルで同じフォルダを上書きし、Chromeの拡張機能画面で拡張を再読み込みしてから、ゲームを再読み込みしてください。

## 予測の出典

[アーティファクト成長予測 v9](https://artifact-v9.netlify.app/) の経験式と丸め方を使用しています。ゲームの公式計算式ではないため、実際の強化結果とはずれることがあります。

拡張が動くのは `arkhomu.com` のページ上だけです。予測と絞り込みはブラウザ内で完結し、通信やゲーム操作は追加しません。不要になったらChromeの拡張機能画面から無効化できます。

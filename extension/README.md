# はこホム拡張

Tampermonkey／Userscripts版の「拡張設定」→「設定の保存先」には「管理アドオン側に保存（Firefox系向け）」があります。初期設定はオフで、オンにすると保存済みのフィルタ条件・プリセット・拡張設定・育成ルート・拡張ボックスなどを管理アドオン内にも保存し、サイトデータが消えた次回起動時に復元します。AFの条件はプリセットとして保存したものが対象です。探索統計・ログイン情報と一時キャッシュは含めず、端末間の自動同期は行いません。オフにすると管理アドオン側の保存分だけを削除します。初回利用にはスクリプト本体の上書きが必要で、通常のPC用拡張にはこの項目を出しません。

育成ルートを設定した個体詳細の「育成ルートを共有」から、未習得の目標スキルもリンクで共有できます。プランナーとルート編集画面にも同じボタンがあります。通常・永久、アクティブ・パッシブの区別、控え、スキルLv、R6固有の設定を保持します。受け取った人は「拡張育成ルートに取り込む」→「保存」で新しいルートとして追加できます。

プランナーでは使用枠を超えた行に赤色と「上限超過」を表示します。編集用の37件は維持し、控えとR6固有パッシブは使用枠に数えません。ギルドダンジョンの拡張フィルタは、現在の条件・並び順・未確認の表示設定をこのブラウザに自動保存し、再読み込みや再起動後も復元します。

ギルドダンジョン一覧の「国の区別なく並べる」をオンにすると、読み込み済みの全ダンジョンを本体の並び順・拡張ソートでまとめて並べます。「今日の挑戦が終わったダンジョン」は末尾の別枠にし、「終了分を非表示」で隠すこともできます。国の統合・終了分の非表示はどちらも初期設定オフで、選択はこのブラウザに保存します。

はこホムのアーティファクトが、Lv4000でどのくらいの性能になりそうかをゲーム画面で見比べられるChrome・Edge用の拡張機能です。

- **拡張予測**は、AFの詳細で使えます。Lv4000未満のAFの現在値の下に予測値が出ます。「Lv4000予測をコピー」で予測結果をテキストにできます。Lv4000以上のAFでも、AF変換率とドロップ率の現在の合計を確認できます。スクリーンショットを撮るときなどは、詳細の上部右側にある「予測 ON / OFF」で拡張の表示だけを切り替えられます。設定は別のAFを開いたりページを再読み込みしたりしても引き継がれます。
- **拡張フィルタ**は、装備・強化・分解タブ、フリーマーケット、オークション、個人間取引のアーティファクトタブで使えます。パラメータと特性を検索するか、カテゴリを開いてチェックします。体力などのパラメータも選べ、各項目に下限・上限と、その項目自身の★を指定できます。20%以上なら下限に `20` と入力します。
- **複数条件**はAND（すべて一致）、OR（どれか1つ）、「指定数以上」でつなぎます。会心威力・会心率・会心耐性を追加して「指定数以上」の数を `2` にすると、3項目中2項目以上に一致したAFを表示できます。「＋ グループ」で入れ子にでき、内側のグループは外側の条件では1件として数えます。最低一致数もプリセットに保存できます。
- **拡張フィルタのプリセット**は、名前を入力して「保存」を押します。次回は一覧から名前を選び「読み込み」で、条件、予測値・判定できないAFの表示設定、拡張ソートの設定を戻せます。同じ名前の「上書き保存」で更新できます。プリセットは同じChromeプロファイルの拡張機能内に保存されます。分解タブの「残す」チェックはプリセットに含まれません。
- **拡張ソート**では、ゲームの並び順の先頭から「AF変換率＋ドロップ率合計」を選べます。横の「予測値順」にチェックすると、パワー・パラメータ・特性・合計の順番にLv4000予測値を使います。「拡張フィルタ」の並び順からも、比較する項目と高い順・低い順を選べます。ポップアップで項目を選んだときは、ポップアップ側の並び順を優先します。
- AF画面の並び順と「予測値順」のチェック状態は、画面ごとにこのブラウザへ保存します。画面を閉じたりページを再読み込みしたりしても、最後の選択を復元します。

## 拡張設定

画面右上のメニューで、ゲームの「設定」の隣にある「拡張設定」を開くと、機能を個別にオン／オフにできます。

- 画面下部の **本体更新 #番号** は、ゲームの公式更新履歴の掲載件数です。履歴が前回確認した版から2件増えたときは「（+2）」が付きます。履歴の件数が同じままビルドが変わったときは「（ビルド更新）」と表示します。ラベルにカーソルを合わせると、最新の履歴の日付とビルドIDを確認できます。
- **拡張ガチャ結果**は、AFガチャ・スーパーガチャで公開されたAFのカードにパワー（PW）と、そのレベルでのAF変換率＋ドロップ率合計を表示します。
- AFガチャの投入候補一覧で、拡張フィルタと拡張ソートを使えます。標準の自動セットも、拡張フィルタに一致したAFから候補を選びます。「連続セットの追加候補」の連数は、5個を1連として換算した数です。
- **拡張セット**は、自動セット欄の「拡張セットを使う」にチェックを入れ、「合計パワー以上」の条件を選んでから、標準の「セット」「10連セット」などを押すと使えます。チェックを外すと標準の自動セットに戻ります。チェックの初期値はオフで、最後に選んだ状態をブラウザに保存します。条件を満たす5個組を手持ち全体から計画し、指定の連数までカートに入れます。計画と投入はそれぞれ約2秒を目安に区切ります。残りの組は同じタブで30分間再利用できます。「計画をリセット」を押すと、次のセット時に手持ちから計算し直します。
- **拡張探索結果**では、標準のカードと前後ボタンを使いながら、「標準の件数」「全件表示」「優先度別ページ」を切り替えられます。全AFレアリティ・通常アイテム・特殊アイテム・魂・卵などの表示順とページ割り当ては「拡張設定」で変更できます。条件に合ったAFは赤い枠と「✓」が付き、一致した項目名と値が最大2件出ます。「✓」のある欄を押すと、すべての一致条件を上下限・★と合わせて確認できます。並び順に使った項目と値は別の段に出ます。「→」はLv4000予測を示します。枠の色と、候補を先頭に寄せるか候補に絞るかは拡張設定で選べます。
- **AFドロップ合計**は、探索結果で獲得した全レア度のAFの個数を表示します。絞り込みやページ切り替えの前の合計が表示されます。
- **拡張探索統計**の「探索時間」は、「探索開始」または「再び探索」を押してから探索サマリが表示されるまでの経過時間です。通常探索とギルダンの統計の「今回」に表示し、同じタブで再読み込みしても直近の計測結果を表示できます。ギルダンの試走とボス戦にも時間を表示します。
- **拡張探索統計**は、1ストックあたりのAF・経験値・ゴールドと、戦闘の勝率・勝敗数を今回、直近30日（日本時間）、累計で表示します。獲得量は各期間の合計をストック数の合計で割り、勝率は戦績を記録できた結果の合計勝数を合計戦闘数で割ります。通常探索の集計はブラウザ内に保存され、探索結果の「統計をリセット」や「拡張設定 → 拡張探索結果」から次の探索分で集計し直せます。ギルダンは今回分を表示し、勝敗の合計を1ストックあたりの戦闘回数（取得できない場合は5戦）で割って切り上げます。ギルダンの試走や挑戦全体の報酬しか分からない結果、ボス戦、天昇の塔は通常探索の集計対象外です。
- 統計は幅に余裕があれば「通常」と「クローバー有効」を横並びで表示します。狭い画面では「集計対象」から切り替えられます。クローバーの有効回数は勝利時に減ります。途中で効果が切れた探索は、回数と報酬の両方を照合できれば分けて集計します。報酬の内訳を確認できない混在結果は保存対象外です。切り分け導入前の統計も新しい集計の対象外になります。
- **拡張価格追跡**は、通常アイテムや永久スキルを選び、「最安値を追跡」から登録します。通常アイテムはフリマの標準画面に読み込まれた最安値で更新し、永久スキルはスキル個別の価格が分かったときに更新します。追跡中のスキルは「価格を確認」から1件ずつ確認でき、出品が複数ページあるときは標準の「価格が安い順」で確認できます。100件まで、商品ごとに価格が変わった時点を最大90回このブラウザに保存します。
- **拡張称号**では、プロフィールの「称号設定 → 隠し称号」に、未取得の称号が鍵付きで並びます。標準の検索や「獲得済みだけ」が使えます。鍵付きの称号も入手条件を確認でき、数値が不明な箇所は `N` で表示します。
- **拡張強化見積もり**は、AF強化画面で対象を選び、必要素材の下にある「拡張強化見積もり（Lv4000）」を開くと見られます。期待値と約90%到達に必要な素材数、素材代、研究軽減込みの強化費用、合計が表示されます。「フリマの売上平均を取得・反映」を押すと、同じタブ内でその素材のフリマを読み込み、売上平均を素材単価に反映します。取得した値は同じブラウザで24時間使えます。単価を手入力している場合は、その金額が優先されます。
- **拡張スキルプリセット**は、ホムンクルスごとに使用中と控えの状態を保存します。プリセットを選ぶと変更箇所を表示するので、ゲームの控えボタンで切り替えてください。
- 強化画面でAFを切り替えても、拡張強化見積もりの開閉状態と素材ごとの手入力単価を保持します。Lv4000以上のAFから強化途中のAFに戻ったときも見積もりを表示します。
- **拡張編成共有**は、パーティ編成画面の「拡張編成共有」から前衛・後衛の配置、世代、ボーナスパラメータ、使用中のスキルを一覧で表示します。「画像を保存」で一覧全体を1枚のPNGにできます。「共有リンクをコピー」で拡張を入れた相手に渡せます。長い編成は「編成ファイルを保存」で渡し、受け取った側が「拡張設定 → 編成ファイルを開く」から表示できます。
- 殿堂では、編成が表示されている探索・ギルドなどの投稿で、コメント欄へ移動するボタンの横に「この編成を共有・育成に使う」が出ます。共有リンクのコピーや各個体の拡張育成ルートへの取り込みができます。
- **拡張育成ルート**は、通常・永久スキルの目標を保存し、ホムンクルス詳細の「拡張育成ルートを読み込む」で個体に割り当てます。合成の継承候補や永久スキル付与で目標のスキルに目印が付きます。
- 個体の「設定中のルートを編集」から内容を変更・削除できます。訓練所の「スキル付与」では、対象個体にまだ付与していない必要永久スキルが所持スキル一覧の先頭に出ます。
- 共有された個体を育成ルートに取り込むとき、R6固有スキルは通常枠から除外します。以前に作られたリンクやファイルでは、ブラウザに読み込まれた図鑑データからR6固有スキルを照合します。
- 合成画面の「継承候補の強調」には、親個体に設定した育成ルートが初期表示されます。両親のルートが異なる場合は、両方の必要スキルを強調します。ルートを1つに絞ると、選択済みのルート外スキルや外せる自動習得スキルに、外す候補の目印が付きます。
- 親に割り当てたルートを選んだときは、「覚える・覚えない」を一括選択できます。初期設定はオンで、合成は確認画面から実行します。
- 個体詳細の「世代上げ母体に指定」で、母体と世代1000未満の素材による継承合成を短縮できます。母体同士の合成や高世代の素材消費、母体の魂化・解放などは実行前に確認します。
- 合成はクラシックの旧UI・新UIとフレックスに対応します。新UI・フレックスでは「継承」の子を選ぶ操作から世代上げ母体の継承を短縮でき、確認欄でも必要スキルと控えの目印を表示します。通常合成の候補は短縮の対象外です。
- 育成ルートを設定した個体の詳細で「不足」を開くと、足りない通常・永久スキルを確認できます。図鑑データが読み込まれている場合は、習得するホムンクルスを習得Lvの低い順に並べ、元ランクも表示します。同じホムから複数の不足通常スキルを継承できる場合は「※別スキルも重複あり」を表示し、押すとほかのスキル名と種別・習得Lvを確認できます。同名のアクティブとパッシブは入手元に種別を表示します。付与アイテムや合成レシピなども確認できます。
- プランナーで作成・保存したルートと、個体や共有リンクから取り込むルートは、スキル名に「【アクティブ】」「【パッシブ】」を付けて保存し、同名でも別々に選択・控え設定・不足判定できます。以前の名前だけのルートも読み込めます。種別が未指定の古い項目は、プランナーで種別を選んで保存すると区別できます。
- 育成ルートを割り当てた親の合成では、選択した継承内容で不足通常スキルが増えない場合や、相方のレベルを上げると不足スキルの継承候補が増える場合に確認します。世代上げ母体・高世代の警告とまとめて1回の確認に表示し、同じ合成の通信再試行では重複して確認しません。
- **拡張育成プランナー**のスキル選択では、名前・ID・効果・タグ、探索などのカテゴリ、固有スキル、新規のみ・スキルレベルありで絞り込めます。スキル名を押すと、説明と効果の詳細を確認できます。
- **拡張初回報酬**は、出撃先ダンジョン選択のメインタブで、初回未取得かつポーションによるスタミナ収支が黒字のダンジョンに絞り込めます。ダンジョン名の行を開くとフロア・難易度別の個数と収支を表示します。未解放のフロア・難易度も対象にでき、設定を保存します。収支はポーション1個＝10ストック、道中0勝から全勝・ボス一発クリアの場合の各フロア単体の目安で、自然回復や前提条件の解放コストは含みません。
- **拡張通知**は項目別にオン／オフにできます。最後の開閉状態は再読み込み後も引き継がれます。NPCショップ・ギルドショップ・ギルドボスは、当日分の実績を確認するまで「未実行（未確認）」と表示します。画面で確認した状態をこのブラウザに保存し、日本時間の0時に日次分を更新します。NPCショップの陳列が先に更新される場合はその時刻、勲章交換は週の更新時刻が区切りです。
- **孵化**は完了時刻が最も早い1件を「最短の孵化予定」と表示します。終了間近のオークションは、ホームにあるゲーム標準の欄で確認できます。
- **拡張通知**のスロット項目は、「拡張設定 → 拡張通知」で低・中・高・超高レートの通知を個別に切り替えられます。スロット画面で確認した今の部の残り回転数を表示します。部の切り替えは日本時間3:30と19:30です。超高レートは確認できる国営ホールで読み込みます。
- **ギルドボスの通知**は、標準画面の「本日の残り参加回数」を読み取ります。画面を開けば、別の端末で消化した分も反映されます。このブラウザで確認した当日の戦果でも更新し、残り0回で通知が消えます。模擬戦と返却された挑戦は回数に含めません。
- **その他の通知**では、採取地の満杯やコロシアムの未使用チケット数などを表示します。
- **拡張スロット**は、継続ストックや決戦の情報を表示します。PCでは着席後の「Homeで並行する」でゲーム画面と並べて表示し、チャットと切り替えられます。
- **拡張チャット**では、引用を押すと表示中の返信元へ移動します。返信元が非表示の場合は、読み込み済みの元の本文か、返信に保存された引用をその場で1件だけ表示します。本体が引用欄も隠しているときは「非表示の返信元を見る」から開けます。
- **拡張日次収支**では、日本時間の0時で日付を切り替え、その日に最初に確認できた残高からゴールドとスタミナポーションの増減を表示します。
- 図鑑のスキン一覧では、「拡張ソート（未入手を先に）」を押すと未入手のスキンが先に並びます。

### 拡張通知で通常アイテムの所持数を表示する

1. ゲームの「持ち物」で「通常」タブを開きます。
2. アイテム倉庫でアイテムを選び、詳細欄の「拡張通知に追加」を押します。複数登録できます。
3. 必要なら同じ欄に目標数を入れます。ホームの拡張通知に「黒曜石 84,000 / 100,000」のように表示され、到達すると「目標達成」が付きます。解除もアイテム詳細から行います。

ゲームが所持数を読み込むと表示も更新されます。再読み込み直後など、所持数を確認できない間は前回確認した個数と時刻を表示します。目標数と登録内容はアカウントごとにこのブラウザに保存されます。
ホームの素材通知を押すと、倉庫で該当アイテムの詳細を開きます。

## 入れ方

1. ZIPを展開します。
2. Chromeのアドレス欄で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` が入っている `arkhomu-af-lv4000` フォルダを選びます。
4. はこホムを再読み込みして、AF一覧の「並び替え・絞り込み」にある「拡張フィルタ」を開きます。

Edgeでは `edge://extensions` を開いて、同じようにフォルダを読み込みます。

## 分解するAFを選ぶ

1. 分解タブの「拡張フィルタ」で、残したいAFの条件を作ります。
2. 一致したAFを確認し、残したいカードの「残す」にチェックを付けます。「一覧の一致をすべて残す」でもまとめてチェックできます。
3. 条件外だけを見たい場合は「条件に一致しないAF」、一致していても残すチェックを付けなかったAFを含める場合は「残すチェックがないAF」に切り替えます。装備中・お気に入り・装備プリセット登録中のAFや、判定できないAFは分解候補から外れます。
4. ゲームの一括解体モードで表示されたカードを選択し、ゲーム側の確認画面で対象を確認します。残すチェックは拡張内の目印です。ゲーム側に前の選択が残っている場合は、いったん選択を終了してから選び直してください。

## 拡張フィルタの範囲

装備・強化・分解では、ゲームが読み込んだ一覧を先に絞り込むので、「全件」表示でも一致するAFが上から詰まります。フリマとオークションの絞り込みと予測値順は、いま開いているページが対象です。オークションでは「開催中の出品」にある「拡張フィルタ」から、条件と並び順を設定できます。ページを切り替えても条件は引き継がれます。標準の特性条件に下限を入れると現在値で先に除外されるので、予測値で比較したい下限は拡張の欄に入れてください。値を読み取れないAFがある場合は「判定できないAFも表示」で一覧に戻せます。

すでに前の版を入れている場合は、新しいファイルで同じフォルダを上書きし、Chromeの拡張機能画面で拡張を再読み込みしてから、ゲームを再読み込みしてください。

## 予測の出典

[アーティファクト成長予測 v9](https://artifact-v9.netlify.app/) の経験式と丸め方を使用しています。ゲームの公式計算式ではないため、実際の強化結果とはずれることがあります。

拡張が動くのは `arkhomu.com` のページ上だけです。予測と絞り込みはブラウザ内で完結し、通信やゲーム操作は追加しません。不要になったらChromeの拡張機能画面から無効化できます。

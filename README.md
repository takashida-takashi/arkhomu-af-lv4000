# はこホム拡張

「方舟のホムンクルス」向けのブラウザー拡張です。拡張予測・拡張フィルタ・拡張ソートでAFを比較できます。拡張探索統計、拡張通知、拡張編成共有などの機能もあります。

- [PC・Android・iPhoneの配布ページ](https://takashida-takashi.github.io/arkhomu-af-lv4000/)
- [画像付きの使い方](https://takashida-takashi.github.io/arkhomu-af-lv4000/guide/)
- [機能と使い方](extension/README.md)
- [開発に参加する](CONTRIBUTING.md)

機能提案や不具合報告は [Issues](https://github.com/takashida-takashi/arkhomu-af-lv4000/issues) へどうぞ。コードの変更は、このリポジトリをフォークしてプルリクエストを送れます。

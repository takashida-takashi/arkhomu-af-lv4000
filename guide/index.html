導入・更新

PC

  1. PC用ZIPを展開
  2. Chrome／Edgeの拡張機能でデベロッパーモードをオン
  3. 「パッケージ化されていない拡張機能を読み込む」から、manifest.jsonのあるフォルダーを選択

Android

  1. FirefoxにTampermonkeyを追加
  2. 配布ページの「Tampermonkey用を開く」を押す
  3. Tampermonkeyの確認画面でインストール

iPhone・iPad

  1. Userscriptsを入れ、Safariの機能拡張で有効にする
  2. Safariで配布ページの「Userscripts用を開く」を押す
  3. ページメニューからUserscriptsを開き、インストール

画面下の「拡張 v…」を押すと更新を確認します。PCでZIPの適用が必要な場合は、既存フォルダーに上書きして拡張を再読み込みします。Android・iPhone・iPadでは、取得済みの更新が次回のページ読み込みで有効になります。

拡張設定

ホームの上部メニューから「拡張設定」を開きます。機能ごとのオン／オフ、ホームに表示する通知項目、探索結果の表示順などを変更できます。

AF強化後予測値表示

条件の保存・読み込み

  1. 拡張フィルタで条件と並び順を設定
  2. プリセット名を入力して「保存」
  3. 次回は名前を選び「読み込み」

予測値で並べ替え

  1. 一覧の「予測値順」をオン
  2. 並び順で比較する値を選択
  3. 例として「AF変換率＋ドロップ率合計」の高い順で表示

分解するAFを選別する

  1. 分解タブの拡張フィルタで
    残したい条件を設定
  2. 一致を確認して
    「一覧の一致をすべて残す」
  3. 「残すチェックがないAF」
    に切り替え
  4. 標準の分解画面で
    選択したAFを確認して実行

フリマ・オークションの比較は表示中のページが対象です。予測値で比較する下限は拡張フィルタに入力します。

探索結果の見やすさ向上

表示優先度・ページの割り当て・一致枠の色は「拡張設定 → 拡張探索結果」で変更できます。統計は通常とクローバー有効を横並びで比較でき、狭い画面では「集計対象」から切り替えます。編成変更後は「統計をリセット」で集計を始め直せます。

編成共有・育成ルート

  1. パーティ・個体詳細・殿堂から
    編成や個体を共有
  2. リンクを開き、使いたい枠の
    「拡張育成ルートに取り込む」
  3. 通常・永久スキルを確認して保存
    新規ルートは拡張設定から作成
  4. 育てる個体を開き
    「拡張育成ルートを読み込む」

保存済みのルートでは「通常・永久の入れ替え」を使えます。片方のスキルを選ぶと移動し、両方で選ぶと入れ替えます。変更後は「保存」を押します。

合成操作性向上

一括選択は初期設定でオンです。ゲームの枠・ポイント・スキルロックに従って選択します。両親に別々のルートがある場合は、使いたい親のルートを選んでから確認してください。

世代上げの継承を短縮する

  1. 個体詳細で
    「世代上げ母体に指定」
  2. 合成の親を
    母体1体と世代1000未満の素材1体にする
  3. 候補詳細の
    「このホムンクルスを継承生成する」を押す
  4. 合成結果を確認
    生まれた個体に母体指定を引き継ぐ

Flexレイアウトでは候補詳細の「この子を選ぶ」から進めます。母体同士の合成や高世代の素材消費、母体・高世代個体の魂化・解放では続行するかを確認します。ゲーム側のお気に入り同士の確認が出た場合は、画面で選択してください。

通知項目追加

  1. アイテム倉庫 → 通常
    登録したい品を選ぶ
  2. 「拡張通知に追加」
    必要なら目標数を入力
  3. ホーム → 拡張通知
    所持数・目標達成を確認
  4. アイテム名を押す
    倉庫でその品の詳細を開く

「拡張設定 → 拡張通知」で、ホームに表示するショップ・ギルドボス・遠征・孵化・スロットなどの項目を選べます。ギルドボスは自分の参加残数、スロットはレートごとの残り回転数を表示します。

AFガチャ周辺の機能追加

「拡張セットを使う」をオンにすると、投入できる所持AFを組み合わせ、できるだけ多く引けるようにセットします。理論上限に達した場合は「最大○連」と表示します。

拡張ガチャ結果をオンにすると、AFガチャ・スーパーガチャで公開したAFのカードにPWとAF変換率＋ドロップ率合計が表示されます。

その他の機能

フリマの価格追跡

  1. フリマで通常アイテム・永久スキルを選ぶ
  2. 「最安値を追跡」を押す
  3. 「最安値の推移」で履歴を確認

控えの配置を保存

  1. ホムンクルス詳細のスキルを開く
  2. プリセット名を入れ「現在の控えを保存」
  3. 読み込んだ差分を見て控えボタンで切替

隠し称号・スキン

  1. プロフィールの「称号設定 → 隠し称号」を開く
  2. 鍵付きの称号を押して入手条件を見る
  3. スキンは図鑑の「拡張ソート（未入手を先に）」

スロットの並行表示

  1. PCで台に座る
  2. 台の上部の「Homeで並行する」を押す
  3. 「チャットを表示」で切り替える

チャットの返信元

  1. チャットの引用を押す
  2. 返信元に移動。非表示の場合はその投稿を表示
  3. 引用も隠れていれば「非表示の返信元を見る」を押す

日次収支

  1. 拡張設定で「拡張日次収支」をオン
  2. ゴールド・ポーションの当日増減を確認
  3. 日本時間0時で日付が切り替わる
